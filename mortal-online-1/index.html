MO1 skill system

MO1 uses Primary and Secondary skills. Secondary skills do not use the Primary skill budget.

01

Primary skills

These skills use the character point budget.

02

Secondary skills

These skills support a build without using that budget.

Deva and World

Editable cap

The planner starts at the historic 1,000-point cap. You can change it.
